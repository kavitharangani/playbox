# Playbox

A game app with 28 games for every age. Pick a game, play it, and chase first place on the leaderboard.

## 🎮 Live demo

**[https://kavitharangani.github.io/playbox/](https://kavitharangani.github.io/playbox/)**

## Features

- 28 playable games, grouped by age: **Child**, **Junior** and **Senior**
- Search by name, category or keyword, with category filters
- Your score, place and best results saved for every game
- Leaderboards, recent plays and more than one player on a device
- Five colour themes, sound effects and animations
- Works on phones and computers, can be installed, and plays offline

## Games

| Group | Games |
|---|---|
| **Child** | Memory Match, Whack-a-Mole, Quick Math, Tic-Tac-Toe, Color Sequence, Balloon Pop, Shape Match, Count With Me |
| **Junior** | Snake, 2048, Sky Hopper, Brick Breaker, Minesweeper, Word Guess, Space Shooter, Stack Tower, Reaction Rush, Highway Racer, Bike Rush, Target Range, Sudoku, Four in a Row, Speed Typing |
| **Senior** | Reversi, Code Breaker, Sliding Puzzle, Expert Sudoku, Expert Minesweeper |

Scores are saved in your browser, so they stay on the device you played on.

## Built with

React, Vite and React Router.

## Run it on your computer

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
npm run dev
```

Then open the address shown in the terminal, usually http://localhost:5173.

## Publish an update

```bash
npm run deploy
```

This builds the app and publishes it to GitHub Pages.
